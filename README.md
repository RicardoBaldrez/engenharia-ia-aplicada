# Engenharia de IA Aplicada

Exercícios e projetos práticos da pós-graduação em Engenharia de IA Aplicada: redes neurais, machine learning, deep learning e LLMs.

## Estrutura

Cada disciplina tem sua pasta, dividida por módulo. Cada módulo guarda os exemplos e exercícios daquela etapa.

```
<Disciplina>/
  ModuloXX/
    <exemplo-ou-exercicio>/
```

## Conteúdo

| Módulo | Projeto | Descrição |
| ------ | ------- | --------- |

## Como rodar

Cada projeto é independente. Entre na pasta dele e rode:

```
npm install
npm start
```
